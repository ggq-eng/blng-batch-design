执行摘要

本 Skill 用 Edge 浏览器自动化驱动 BLNG（app.blng.ai），在一个对话内连续生成多张珠宝与钻石设计图，按序号自动落盘到指定目录，最后一键合成「一张图片一页」的 PPT。使用者填好账号密码、完成一次登录后，日常跑批即是一条命令。

单张生成耗时 单档建议张数 提示词模板 PPT 版式

约 76 秒

25 – 50 张

300 条

一图一页

使用前需完成三件事：填写账号密码、执行一次登录、用 3 张图自检链路。之后按切片方式跑批，最后一键出 PPT。

一、这个 Skill 能做什么

本 Skill 把「BLNG 网页端手工出图」沉淀为可复用的自动化管线，核心能力如下。

能力状态说明
单对话连续出图支持提示词逐条提交，在同一项目内累积生成
按序命名落盘支持文件名格式「序号_款式名.png」，如 001_design_001.png
断点续跑支持目录内已存在且大于 1KB 的图片自动跳过，重复跑同一区间是安全的
一图一页 PPT支持自动生成，并校验页数与每页内嵌图片 MD5
免费版突破单日总量不支持免费版无每日上限，但同时仅允许 3 个活跃设计文件
跨对话复用旧项目续跑不支持BLNG 会清理免费档旧项目，续跑须新开项目

速度参考：实测约 76 秒每张。50 张约 1 小时，250 张约 5.3 小时。因此大批量任务必须切片执行，详见第六节。

二、前置要求

正式跑批前，请先确认运行环境、依赖与相关版本均已就绪。以下三节分别说明环境清单、依赖安装与文档信息。

（一）环境清单

项要求用途
操作系统Windows依赖本机 Edge 的调试端口
浏览器Microsoft Edge无需 Chrome 或 Chromium，直接复用本机 Edge
Python3.10 及以上运行全部脚本
Node.js18 及以上仅在合成 PPT 时需要
PPT 引擎@tencent/slidep合成 PPT 时需要
网络可直连 BLNG若走系统代理，脚本已内置回环地址排除

（二）依赖安装

Python 依赖安装到受管虚拟环境：

终端命令

PY=/c/Users/Administrator/.workbuddy/binaries/python/envs/default/Scripts/python.exe

"$PY" -m pip install browser-use websockets

  必须使用上述虚拟环境解释器运行脚本，不要使用系统自带的 python。系统 Python 缺少 websockets 模块，执行时会报错 ModuleNotFoundError: No module named 'websockets'。本文后续所有 python xxx.py 命令，均请理解为 "$PY" xxx.py。

确认 PPT 引擎可用：

终端命令

node -e "console.log(require.resolve('@tencent/slidep/dist/index.js'))"

若提示找不到模块，请执行 npm install -g @tencent/slidep 安装。

三、Step 1：填写账号密码

凭据文件位于 scripts/blng_session.py。该文件交付时账号密码为空，需使用者自行填写。打开后找到如下片段：

blng_session.py 片段

# ============================================================

# 凭据配置 —— 使用前请填写你自己的 BLNG 账号

# ============================================================

# 方式一（推荐）：直接填写下面两行

EMAIL = ""

PASSWORD = ""

# 方式二：设置环境变量 BLNG_EMAIL / BLNG_PASSWORD（优先级高于上面的填写）

方式一：直接填写。把 EMAIL 与 PASSWORD 填成自己的 BLNG 账号：

blng_session.py

EMAIL = "你的账号@example.com"

PASSWORD = "你的密码"

方式二：环境变量。保持文件内为空，运行时注入：

终端命令

export BLNG_EMAIL="你的账号@example.com"

export BLNG_PASSWORD="你的密码"

  环境变量优先级高于文件内填写；两者同时设置时，以环境变量为准。

  请勿将填好真实密码的 blng_session.py 提交到公开仓库或对外分享。

预期结果：文件中 EMAIL 与 PASSWORD 已填入有效值，或环境变量已设置。

四、Step 2：首次登录

登录会把认证态落盘为会话快照，之后跑批自动注入，无需重复登录。

终端命令

cd 到 skill 安装目录下的 scripts 子目录

NO_PROXY='localhost,127.0.0.1,::1,0.0.0.0' HTTP_PROXY='' HTTPS_PROXY='' \

  "$PY" blng_session.py login

预期输出：

预期输出

{ "ok": true, "url": "https://app.blng.ai/dashboard", "logged_in": true }

脚本执行过程：后台拉起 Edge（调试端口 9222，独立用户目录 .edge-profile/），自动填写邮箱密码并提交，导出会话到 scripts/.blng_session.json。

检查登录态（不重新登录）：

终端命令

NO_PROXY='localhost,127.0.0.1,::1,0.0.0.0' HTTP_PROXY='' HTTPS_PROXY='' \

  "$PY" blng_session.py status

返回 "logged_in": true 即为就绪。

  所有命令必须带上 NO_PROXY='localhost,127.0.0.1,::1,0.0.0.0' HTTP_PROXY='' HTTPS_PROXY='' 前缀。系统代理会劫持本地调试端口，导致连接失败（502）。

五、Step 3：链路自检

首次使用建议先跑 3 张图，验证整条链路。以下三个小步骤依次完成提示词生成、账号容量核对与实际出图。

第 1 步：生成一份小的提示词清单（5 条）。

终端命令

"$PY" gen_prompts.py 5 design_prompts.json

预期输出：生成 5 条，输出文件 design_prompts.json

第 2 步：检查账号当前的活跃设计文件数。

终端命令

"$PY" check_projects.py

预期输出：显示当前活跃设计文件数与方案上限（免费版上限为 3）。

第 3 步：跑 3 张图。

终端命令

NO_PROXY='localhost,127.0.0.1,::1,0.0.0.0' HTTP_PROXY='' HTTPS_PROXY='' \

  "$PY" blng_conversation.py --file design_prompts.json --name smoke --start 1 --end 3

预期结果：约 4 分钟后，到 D:\Desktop\新建文件夹 (2)\设计图 目录下查看，应出现：

落盘文件

001_design_001.png

002_design_002.png

003_design_003.png

出现这三张图，说明整条链路已打通。

六、Step 4：批量出图（核心步骤）

本节是整条管线的主体：先准备完整提示词清单，再按序号窗口切片跑批，并掌握切片大小的取舍原则。

（一）准备完整提示词清单

终端命令

"$PY" gen_prompts.py 300 design_prompts.json

该脚本按「10 品类 × 10 宝石 × 3 金属」组合生成 300 条珠宝设计提示词。也可使用自己的清单，只需保持如下字段结构：

design_prompts.json

[

  { "name": "design_001", "prompt": "an engagement ring featuring a round brilliant-cut diamond ..." }

]

（二）切片跑批

按序号窗口分批推进。以下示例跑第 1 至第 50 张：

终端命令

NO_PROXY='localhost,127.0.0.1,::1,0.0.0.0' HTTP_PROXY='' HTTPS_PROXY='' \

  "$PY" blng_conversation.py \

    --file design_prompts.json \

    --name design_run \

    --start 1 --end 50

  落盘目录已写死为 D:\Desktop\新建文件夹 (2)\设计图，无需再传 --out-dir。

预期输出（节选）：

预期输出

[1/50] (#1) design_001

   click[New Design] 完成

   生成中... 完成

   已保存 001_design_001.png

...

[50/50] (#50) design_050

   已保存 050_design_050.png

预期结果：D:\Desktop\新建文件夹 (2)\设计图 下累积 50 张图片，并生成 manifest.json 记录出图明细。

（三）关于切片大小

受执行环境限制，单次命令超过 10 分钟会被中断。建议按以下档位推进：

单档张数预计耗时说明
25约 32 分钟稳妥档位
50约 64 分钟常用档位，接近上限

更大批量请按 50 一档递进：跑完 1-50，再跑 51-100，以此类推。

  不要复用旧项目续跑。免费档项目会被 BLNG 清理，深链会在数秒后跳回首页导致失败。每档请新开项目，让脚本从首页自动新建入口进入。

  目录内已存在且大于 1KB 的图片会自动跳过。因此重复执行同一区间不会重复消耗额度，中断后直接重跑该档即可。

七、Step 5：合成 PPT

出图完成后，用一条命令把整个目录合成 PPT。

终端命令

"$PY" make_ppt.py --force

  参数已写死默认：读取目录 D:\Desktop\新建文件夹 (2)\设计图，输出文件 D:\Desktop\新建文件夹 (2)\设计图集.pptx。

预期输出：

预期输出

{ "ok": true, "slides": 50, "images": 50, "failed": [] }

预期结果：生成 设计图集.pptx，共 50 页，每个页面放置一张图片，页面版式为白色背景、图片居中、右下角显示页码（格式如 01/50）。脚本会在生成后自动校验页数与每页内嵌图片的 MD5，不通过则报错。

八、参数速查

以下两张表列出两个主脚本的全部命令行参数，均给出默认值，便于按需覆盖。

（一）blng_conversation.py

参数必填默认值说明
--file是—提示词清单 JSON 路径
--name否conversation任务名，用于日志与目录标识
--start否1起始序号（含）
--end否到清单末尾结束序号（含）
--out-dir否D:\Desktop\新建文件夹 (2)\设计图图片落盘目录
--reuse-dir否—显式复用输出目录
--reuse-url否—复用项目 URL（仅同一次会话内有效）

（二）make_ppt.py

参数必填默认值说明
--dir否D:\Desktop\新建文件夹 (2)\设计图图片目录
--out否D:\Desktop\新建文件夹 (2)\设计图集.pptx输出 PPT 路径
--force否关闭强制重建，覆盖已有 PPT

（三）路径覆盖方式

如需临时改用其他目录，可用命令行参数覆盖：图片目录用 --out-dir，PPT 输入目录用 --dir，PPT 输出文件用 --out。也可设置环境变量 BLNG_OUT_DIR（图片目录）与 BLNG_PPT_OUT（PPT 输出）。

九、关键约束与避坑（必读）

以下六条是本管线最容易踩的坑，建议在正式跑批前逐条确认。

  1. 必须排除回环代理。所有联网命令都要加 NO_PROXY='localhost,127.0.0.1,::1,0.0.0.0' HTTP_PROXY='' HTTPS_PROXY='' 前缀。
  2. 单次命令 10 分钟上限。大批量必须切片，否则会被中断。
  3. 不要复用旧项目。每档新开项目，中断后重跑同档即可（已完成的图会自动跳过）。
  4. 免费版同时仅 3 个活跃设计文件。跑批前可用 check_projects.py 核对；若已占满，先到网页端清理，或使用付费账号。
  5. 会话有效期。登录态中 accessToken 约 1 小时过期、refreshToken 约 30 天。脚本每次跑批前会自动检查：有效则复用，失效则用凭据重新登录。
  6. 运行时文件包含凭证。scripts/.blng_session.json 内含登录令牌，scripts/.edge-profile/ 内含浏览器登录状态。二次分发前请删除这两个路径。

十、常见问题 FAQ

下表汇总使用过程中最常见的七类问题及其定位与处理方式。

问题原因与处理
报错 ModuleNotFoundError: No module named 'websockets'使用了错误的 Python 解释器。请改用受管虚拟环境解释器 /c/Users/Administrator/.workbuddy/binaries/python/envs/default/Scripts/python.exe
登录或跑批时报连接失败（502）未排除系统代理。请在命令前加上 NO_PROXY='localhost,127.0.0.1,::1,0.0.0.0' HTTP_PROXY='' HTTPS_PROXY=''

跑批中途中断，需要从头再来吗不需要。直接重跑同一档区间即可，已生成且大于 1KB 的图片会被自动跳过
合成 PPT 报错找不到 node 或引擎请确认已安装 Node.js 18 以上版本及 @tencent/slidep。也可通过环境变量 BLNG_NODE 指定 node 路径
生成的图片有重复内容脚本内置像素哈希去重，命中重复会自动重试。若重试后仍重复，属模型输出的偶发情况，可单独重跑该序号
可以修改落盘目录吗可以。使用 --out-dir 参数覆盖，或设置环境变量 BLNG_OUT_DIR
