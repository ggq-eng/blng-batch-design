# BLNG 批量出图使用说明

本文说明这套工具能做什么、用之前需要准备什么、以及具体怎么操作。

## 一、能做什么

这套工具用来自动在 BLNG 网站上批量生成珠宝和钻石设计图，并把图片整理成 PPT。具体说来是四件事。

第一，自动出图。只要给它一份设计描述清单，它就会在同一个对话里一张接一张地生成，不需要人守在旁边一张张点。

第二，自动存图。生成好的图片会自动保存到指定文件夹，并按顺序编号命名，方便查找和排序。

第三，自动做 PPT。图片全部生成完之后，运行一次就能得到一个 PPT，每一页放一张图。

第四，断点续跑。如果中途中断，直接重跑就行，已经生成好的图片会自动跳过，不会重复生成，也不会浪费额度。

有两点需要提前知道。一是免费版账号没有每日总量限制，但同时最多只能保留 3 个设计文件，用满了要先清理。二是生成速度大约是每张 76 秒，50 张大约需要 1 小时，所以量大时建议分批进行。

## 二、需要什么

用之前需要准备四样东西。

第一，一台 Windows 电脑，并且安装了 Edge 浏览器。

第二，一个 BLNG 账号。免费版就能用；如果出图量大、想要更多并行空间，建议用会员版。

第三，电脑上装好 Python 和 Node 两个运行环境。这两样属于一次性准备，装好之后不用再管。

第四，留出足够的时间。按每张 76 秒计算，50 张大约 1 小时，250 张大约需要 5 小时以上。

## 三、要怎么做

一共五步，按顺序走一遍就行。

第一步，填写账号密码。打开脚本文件夹，找到名为 blng_session 的文件，把里面的账号和密码填上。如果不想把密码写进文件，也可以改用环境变量的方式传入，效果一样。

第二步，登录一次。在脚本文件夹里运行 blng_session 完成登录，它会自动打开浏览器把登录做完。登录状态会保存在电脑里，之后就不用再登录了。

第三步，先试跑三张。不要一上来就跑几百张，先跑三张确认整条流程正常。跑完后打开图片文件夹，能看到编号为 001、002、003 的三张图片，就说明没问题。

第四步，正式批量出图。一次建议跑 25 到 50 张，跑完一批再跑下一批。如果中途断了，直接重跑同一批即可。

第五步，生成 PPT。在脚本文件夹里运行 make_ppt，它会把图片文件夹里的图片全部整理成一个 PPT，每一页放一张图。

最后说保存位置。图片默认保存在 D 盘桌面「新建文件夹 (2)」下面的「设计图」文件夹里；PPT 默认保存在同一层，文件名是「设计图集.pptx」。这两个位置都可以按需调整。
